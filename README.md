# ScamShield AI

**A cybersecurity project for analyzing suspicious URLs and identifying potential scam indicators.**

## About the Project

ScamShield AI is a personal cybersecurity project I'm developing to explore suspicious URL detection, risk scoring, and online threat analysis using Python.

I'm building this project hands-on in Ubuntu while developing my skills in Python, Linux, and cybersecurity.

## Current Features

- Python-based URL analysis
- Checks for suspicious URL characteristics
- Risk scoring and classification
- Initial investigation report workflow

## Technologies

- Python
- Ubuntu Linux
- Command-line tools
- GitHub

## Project Status

**In development.**

I'm continuing to test the detection logic, improve classification accuracy, and work toward additional scam-analysis capabilities.

This is an educational prototype. Its results are not a guarantee that a website is safe or malicious.

## Project Goals

- Improve URL threat detection
- Test against legitimate and suspicious URLs
- Improve the accuracy of risk classifications
- Develop additional scam-analysis features
- Document testing and development progress
